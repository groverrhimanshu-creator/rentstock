RENTAL INVOICE, HSN/SAC AND SOLD ITEMS ON ONE INVOICE  (step 17)

E-MAIL REMINDERS (read this)
By default Laravel does not send real e-mail: it writes the e-mail text into
storage\logs\laravel.log (MAIL_MAILER=log). The "Reminder log" on the Payments screen still fills.
To send real e-mail put your SMTP details in the file .env, for example:

   MAIL_MAILER=smtp
   MAIL_HOST=smtp.yourprovider.com
   MAIL_PORT=587
   MAIL_USERNAME=accounts@yourcompany.com
   MAIL_PASSWORD=your-password
   MAIL_ENCRYPTION=tls
   MAIL_FROM_ADDRESS="accounts@yourcompany.com"
   MAIL_FROM_NAME="${APP_NAME}"

then run:  php artisan config:clear

AUTOMATIC DAILY REMINDERS
The reminders go out by themselves once per day at 9:00 if the computer/server runs this command every day:

   php artisan reminders:send

On Windows: Task Scheduler -> Create Basic Task -> Daily 9:00 -> Start a program:
   Program:   C:\xampp\php\php.exe
   Arguments: artisan reminders:send
   Start in:  C:\xampp\htdocs\rentstock
On Linux hosting: cron  * * * * * cd /path/to/rentstock && php artisan schedule:run >> /dev/null 2>&1

Customers need an e-mail address (Masters > Customer) to get a reminder.

IMPORT ITEMS (Masters > Item > Import items)
Upload the client's Item master sheet (CSV or Excel .xlsx). Columns are found by name:
Product Name, Category, Brand, Unit, HSN Code (or SAC Code), Rental Price, Sale Price, CGST, SGST, IGST,
Parameterized, Generate Barcode, Maintain Stock. Other columns (MRP, Purchase Price, Discount ...) are ignored.
 - Missing categories, brands and units are created automatically.
 - Items already in the master (same name, any capital letters/spaces) are skipped, not changed.
 - Names repeated inside the file: the first is kept, the rest are skipped.
 - Rental Price becomes Rent per month, Sale Price becomes Sale price. GST = CGST + SGST (or IGST); empty = 18.
 - Generate Barcode = Yes -> barcoded item (one barcode per piece). Otherwise counted by quantity.
   When Parameterized and Generate Barcode are both Yes the barcode wins.
 - Maintain Stock = No (quantity items only): the item is not counted in stock. Buying adds no stock, selling checks and
   takes no stock, and it can always be put on a sale or rental invoice. Barcoded items are always kept in stock.
 - Up to 20,000 rows and 10 MB per file.
The same "Maintain stock" box is on the Item form (Masters > Item).
